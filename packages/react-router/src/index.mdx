# **`@reactionable/react-router`**

## Router package for [React Router](https://reactrouter.com/home) integration

<br />

### [📖 Typescript documentation](../docs/react-router/)

<br />

### 🚀 Installation

<br />

#### NPM

```sh
npm install @reactionable/react-router
```

#### Yarn

```sh
yarn add @reactionable/react-router
```

#### pnpm

```sh
pnpm add @reactionable/react-router
```

### 🧾 Usage

#### Setup App

###### In a React App

```tsx
import { App } from "@reactionable/core";
import { useRouterProviderProps } from "@reactionable/react-router";
import { ReactElement } from "react";

const MyApp = (): ReactElement => {
  return <App router={useRouterProviderProps()} />;
};
export default MyApp;
```
